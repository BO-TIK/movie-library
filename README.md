# Movie Library (Личная кинотека)

**Автор:** Анашкин Сергей Сергеевич

## Описание
Приложение для хранения информации о фильмах. Позволяет добавлять фильмы (название, жанр, год, рейтинг), удалять, фильтровать по жанру и году. Данные сохраняются в файл `movies.json`.

## Требования
- Python 3.x
- Стандартные библиотеки: tkinter, json

## Использование
- Заполните поля "Название", "Жанр", "Год", "Рейтинг (0-10)"
- Нажмите "Добавить фильм" – запись появится в таблице
- Для удаления выделите строку и нажмите "Удалить выбранный"
- Для фильтрации введите жанр или год и нажмите "Фильтровать". "Сбросить" – отобразить все фильмы

## Запуск
```bash
python main.py
